# 🚀 React Task Manager App

A modern, responsive, and feature-rich **To-Do List Application** built with **React**, **Tailwind CSS**, and **Lucide Icons**. It includes task category management, priority levels, status filtering, real-time search, progress analytics, dark mode, and local storage persistence.

---

## ✨ Key Features

- 📝 **Task Management**: Create, edit, toggle completion status, and delete tasks.
- 🏷️ **Categorization & Priorities**: Organize tasks by categories (*Work, Personal, Shopping, Health, Other*) and set priorities (*Low, Medium, High*).
- 🔍 **Search & Filtering**: Search tasks instantaneously and filter by status (*All, Pending, Completed*) or categories.
- 📊 **Progress Dashboard**: Interactive completion progress bar and task statistics counter.
- 🌙 **Dark Mode Support**: Seamless toggle between light and dark themes with user preference saved.
- 💾 **Local Storage Persistence**: Tasks and theme preferences automatically persist across browser refreshes.
- 📱 **Fully Responsive UI**: Modern UI designed with Tailwind CSS that works smoothly across mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack

- **Frontend Library**: [React.js](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **State Management**: React `useState` and `useEffect` Hooks
